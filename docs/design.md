# codex Mac系统状态栏 · v0.0.1

实现用户已确认的水流原型，使用 Swift/AppKit 原生菜单栏，不依赖浏览器。

- 水位和右侧百分比表示真实剩余额度（100 − 已用比例），默认选择服务器提供的最短额度周期，可在弹出面板切换。
- 额度通过官方 `codex app-server --stdio` 的 `account/rateLimits/read` 读取，复用 Codex 的既有登录。每 60 秒刷新，可手动刷新。只发送初始化和读取请求，不运行模型任务，不读取或复制登录密钥。
- 独立 App Server 无法获知其他进程加载中的线程状态（已实测返回 notLoaded）。因此只读本地 SQLite 线程索引与 JSONL 任务事件，每 2 秒增量检查，覆盖此 CODEX_HOME 下近 24 小时的本机任务。
- 颜色与流速反映最近明确记录的活动：空闲绿，单任务黄绿，多任务黄橙，4 个及以上红；明确的等待事件暂停动画。完成短暂显示对勾。剩余额度与忙碌程度分离。
- 缺失、损坏、网络断连和过期数据要有明确提示。超过 3 分钟没有新事件的未结束任务标为状态待确认，不伪造完成或真实进度百分比。远程与云任务不在监测范围。
- 无 Dock 图标；点击展开；支持手动刷新、减少动画、登录时启动（默认关闭）、打开 Codex 和退出。面板淡蓝底，适配深色外观。
- 交付可直接运行的 .app、源代码、构建脚本与中文说明，并在本机启动验证。

方案选择：原生 AppKit 能常驻菜单栏且动画成本低；网页原型已完成视觉验证；浏览器不能常驻系统菜单栏，Electron 会额外占用内存，故本次采用 AppKit。
