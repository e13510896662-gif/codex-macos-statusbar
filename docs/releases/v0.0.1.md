# codex Mac系统状态栏 v0.0.1

首次开源发布。在 Mac 顶部菜单栏，用圆形动态水流和百分比查看 Codex **剩余额度**，并用绿到红的颜色变化感受本机任务的并行忙碌程度。

## 安装

1. 下载 `codex-macos-statusbar-v0.0.1-arm64.zip`。
2. 解压，将 **Codex Mac 状态栏.app** 拖到 **Applications / 应用程序**。
3. 打开应用，在菜单栏找到水球并点击展开。

要求 macOS 13+、Apple Silicon，以及已经使用 ChatGPT 账户登录的官方 Codex 桌面应用或 CLI。Intel 用户请按 README 从源码编译。

此包仅本地 ad-hoc 签名，尚未 Apple 公证；macOS 可能要求在隐私与安全性设置中手动确认打开。

## 本次内容

- 真实账户额度查询、剩余百分比和水位、多周期切换、重置倒计时。
- 本机任务开始/执行/明确等待/完成/状态待确认提示。
- 手动刷新、旧数据提示、减少动态效果、可选登录时启动。
- 安装和使用文档、MIT 许可、21 项自动测试。
- GitHub Issues 功能需求与问题反馈表单。

## 限制

任务活动依据当前 Codex 数据目录最近 24 小时本机日志，远程和云任务不在范围内。百分比表示剩余额度，不是任务完成进度。等待状态只在日志提供明确事件时显示。

欢迎通过仓库 Issues 提交更新需求，或对已有需求用 👍 表态。
